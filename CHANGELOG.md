# Driftfall changelog

Written by the Build Changelog Writer (`live/changelog.mjs`). Newest first. Each line says what changed, who made it, and why. The chat message that explains it is named as `channel.jsonl #N`, the number that `node read.mjs` prints.

## 2026-10-22

- **Drift schedule (new, not wired yet)** Added env/drift.mjs and tests/drift.test.mjs (18 tests, all pass). By haiku (Drift owner). Why: TERRITORY.md section 4 needs a seeded, deterministic Drift: 3:00 Bloom in both Flanks, 5:00 Squall over the Centre and Bloom in the Centre, 7:00 and 8:00 Floods in each Natural, 9:00 Quake, 11:00 and 13:00 random, 14:00 The Fall. Every event is announced 30 s (720 ticks) ahead. Nothing imports it yet, so the game is unchanged. (chat #317)

- **Security fix** Changed env/referee.mjs, env/player-worker.mjs, ENV-SPEC.md section 11, SECURITY.md finding 1 and tests/anticheat.test.mjs. By sonnet. Why: the anti-cheat test found that a player's code could read any file, write files, run shell commands and see environment variables, because worker threads share the whole process. Each player now runs as its own child process under Node's permission mode with an empty environment: it can read only its own player file and nothing else (no writes, no child processes, no worker threads, no environment). The player API, the 50 ms think limit and the 1000 ms hard cut-off (the process is now killed) are unchanged. One new rule: a player must be a single self-contained file. The two anti-cheat tests that were marked `todo` now run for real and pass; the forger test sends through `process.send` instead of `parentPort`. Still open and not caused by this change: the 50 MB-reply test fails because commands are copied whole into the log (SECURITY.md finding 2).

- **21:38 UTC** Changed env/referee.mjs (per-command size cap), env/stats.mjs (STATS.referee.commandChars: 1024, one line, added under the squad rule after asking haiku at 21:28 with no answer), ENV-SPEC.md section 11 (one sentence) and SECURITY.md finding 2. By fable (Integration squad B, referee owner). Why: tests/anticheat.test.mjs 'an enormous reply' failed because a 50 MB string in an unknown command field was copied whole into the match log (157 MB). The referee now treats a reply holding any command over 1024 characters of JSON, or one that is not plain JSON (BigInt, cycles), like a non-array reply: error event, empty commands that tick. The command count is not cut, so spec section 10's too-many rule and its test are untouched. anticheat 19/19, referee-limits, log-format, full-match-smoke, sim-determinism, stats-table all pass.
